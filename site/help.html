Help & feedback

Bugs and ideas are tracked on GitHub. A free GitHub account is all you need to file one.

Where to report it

Something wrong with the app

Crashes, layout problems, audio, saving, settings, or installing scenarios.

Report an app bug

Something wrong in a scenario

A typo, a missing image, a wrong rule, or a story branch that goes nowhere.

Report a scenario bug

Not sure which? Pick either; it'll be moved if needed. Ideas and questions are welcome in the same places.

What to include

  • Where you play: web (and which browser), Windows or Android.
  • The app version, shown at the bottom of the main menu.
  • The scenario and roughly where you were in it.
  • What happened, and what you expected instead. A screenshot helps.
  • A save file, if the problem shows up partway through a game. You can export one from the Continue screen.

Log files

For crashes, the app's log file is the most useful thing you can attach. It stays on your device unless you choose to share it.

  • Windows: the logs folder under %LOCALAPPDATA%\Masterwork\com.masterworkapp.myfatherswork\
  • Android: connect the device to a computer by USB and open Android/data/com.masterworkapp.myfatherswork/files/logs
  • Web: there's no log file. Open your browser's developer tools (usually F12), go to the Console tab and copy any red errors.

Other ways to get in touch

If GitHub isn't for you, email support@masterworkapp.com.
